# 路线图

## 当前阶段

Windows Bridge、Android Flutter 客户端、配对/WSS、聊天任务和核心协议已实现。当前仍是 early access；兼容性受 Codex Desktop 私有版本影响。

## 下一步

1. 在实体 Android 上复核配对、撤销、重连、锁屏和 VPN 场景。
2. 为 command/file/permission/MCP 请求补充真实的人工交互验收。
3. 复核长输出、网络断开、Bridge 重启和缓存缺失后的恢复。
4. 增加搜索、改名、归档、置顶和通知前先确认实际使用场景。
5. 维护 Desktop compatibility matrix，未知版本保持安全拒绝。

## 明确不在当前路线

Terminal、通用文件管理、Desktop 窗口控制、账号配置、官方 relay、完整 MCP 管理、iOS 客户端和未验证的私有 API 不属于当前公开交付目标。
