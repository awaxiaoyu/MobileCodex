# MobileCodex Android UI 设计

## 目标

Android 首页只负责 Agent chat。聊天记录、项目上下文和设置位于下层 drawer，通过菜单按钮或右滑显示。整体使用白底、近黑文字、系统字体和克制的阴影。

## 首页

- 顶部左侧是白色圆形菜单按钮，显示三条横线。
- 标题为 Mobile Codex；连接状态显示为小圆点和辅助文字。
- 空状态显示欢迎标题、工作区提示和轻量任务建议。
- 输入框固定在底部，使用圆角白色表面；模式、model 和发送按钮位于第二行。
- 不显示 Ask、Build、Review 导航行。

## 任务页

- 菜单按钮与首页相同，不替换成返回或关闭图标。
- 有项目时标题显示 项目/聊天，无项目时只显示聊天名。
- 用户消息靠右使用浅灰气泡；Agent 内容使用普通正文。
- 任务状态、审批、diff 和附件使用轻量状态行或明确边界。

## 下层菜单

- 宽度约为屏幕 80%，主界面向右移动后完整显示 Chats、Recent 和底部操作区。
- 主界面整体不使用投影；只有和菜单连接的左上、左下圆弧有柔和阴影。
- 菜单与主界面之间保持白色连接处，圆角小而连续。
- Recent 的聊天条目有极浅分隔线；Recent 与底部操作区之间不显示分隔线。
- 左下角是 Chat 新建按钮，右下角是圆形 Settings 按钮。

## 尺寸

以 390px 宽屏幕为基准：

| 项目 | 规格 |
|---|---:|
| 页面左右边距 | 16–17px |
| 顶部栏 | 最小 62px |
| 菜单按钮 | 36 × 36px |
| 页面标题 | 22px |
| 任务标题 | 15px，单行省略 |
| 正文 | 14–15px |
| 输入框外边距 | 13px |
| 菜单宽度 | 屏幕 80% |
| 连接圆角 | 20px 左右 |
| 底部安全区 | 保留系统 Home Indicator |

## 实现边界

UI 由 apps/android 的 Flutter widget 实现；Bridge 协议、任务数据结构和电脑上的执行权限不因 UI 调整而改变。iOS 不属于当前公开实现。
